# 参考动作

此说明记录用户提供的卡包开封视频，并给出模板的可复用实现。原视频不随 skill 分发。

## 视频可见特征

- 米白／暖灰舞台中，中央是一只小尺寸蓝色或粉色 foil 卡包。包面有白色 `holo` 字样和银色四角棱镜星。
- 卡包顶部被撕开，彩虹色条带从开口喷出。
- Blip、Ringo、Cubit、Facet、Nova 五张彩色角色卡一起从包中飞出，再错峰排成一排。卡片落位时保留略有差异的角度。
- 卡片悬停时上抬，带轻微 3D 倾斜。结果底部提供 `Open another pack`。

这是“一包五张同时出场”的动作。不要改成逐张点击翻牌、每次只揭晓一张的流程。

## 模板的时序与实现选择

下表是为重建观感采用的近似时序，不是逐帧测得的原视频参数。时间以 `speed: 1` 为准；其他倍率将所有动画耗时按 `1 / speed` 缩放。

| 相对时间 | 动作 | 视觉重点 |
| --- | --- | --- |
| 0–0.4 秒 | 撕顶、短暂蓄光 | 卡包轻微变形，顶封向右分离，开口开始发亮 |
| 0.4–1.1 秒 | 喷出彩虹条带，卡叠一起飞出 | 卡片在开口附近仍有叠放关系，随后逐渐展开 |
| 1.1–2 秒 | 五卡错峰落位 | 水平方向散开成一排，轻微回弹，各自保留小角度 |
| 约 2 秒后 | 展示结果 | 卡包让位于卡片，结果保持，等待用户重开 |

模板提供点击卡包、向右撕包和开包按钮三种入口；以同一状态推进动画，开包过程中忽略重复触发。卡片使用可聚焦按钮，支持悬停、键盘聚焦和点击高亮；重新开包后恢复起点。键盘支持、点击高亮、窄屏适配及减少动态效果属于模板补充，不能仅凭视频判断为原片功能。

## 换皮时保留的关系

卡包、条带和卡片要共用同一个出场中心。撕顶先于卡片散开；条带强调开口的爆发感，卡片落位后收住动作。五卡的错峰用于产生层次，不应让用户感觉需要等待五次独立抽卡。

用户提供新卡面或品牌时替换视觉素材与文字，保留上述节奏即可。默认 foil 配色、角色图案和细小倾角是可调的实现选择，无需固定为唯一风格。
