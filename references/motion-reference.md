# 参考动作

此说明记录用户提供的卡包开封视频，以及模板在此基础上的实现与扩展。原视频不随 skill 分发。

## 视频可见特征

- 米白／暖灰舞台中，中央是一只小尺寸蓝色或粉色 foil 卡包。包面有白色 `holo` 字样和银色四角棱镜星。
- 卡包顶部被撕开，彩虹色条带从开口喷出。
- Blip、Ringo、Cubit、Facet、Nova 五张彩色角色卡一起从包中飞出，再错峰排成一排。卡片落位时保留略有差异的角度。
- 卡片悬停时上抬，带轻微 3D 倾斜。结果底部提供 `Open another pack`。

这是“一包五张同时出场”的动作。不要改成逐张点击翻牌、每次只揭晓一张的流程。

## 撕包阶段（由用户操作驱动）

撕包不计时，跟随用户操作推进：

| 操作 | 反馈 |
| --- | --- |
| 悬停或聚焦卡包 | 卡包上浮 10px、放大 1.05 倍，外圈按卡包颜色发光，表面循环扫光；撕口位置出现虚线和向右移动的光点；随指针轻微 3D 倾斜 |
| 单击（Enter/空格） | 卡包左右抖动约 0.46 秒，伴随低沉“咚”声；提示文字放大闪动，状态栏提示需要滑动 |
| 按住向右滑动 | 撕痕沿预生成的锯齿线推进到指针位置；左侧已撕开的条带以撕口前端为支点翘起，最多约 27°；撕口白色描边，并按本包最高稀有度发光；裂口喷出彩色火花和短条，伴随撕纸颗粒声 |
| 中途松手 | 已撕部分保留，状态栏提示继续；下次从当前进度接着撕 |
| 右方向键 | 每次推进四分之一宽度 |

撕痕位置按“剩余宽度”映射：从卡包左缘开始拖时，撕痕基本与指针重合；从中间开始拖时，撕痕加速推进，指针到达右缘时刚好撕完。

## 开包阶段的时序

下表是为重建观感采用的近似时序，不是逐帧测得的原视频参数。时间从撕到头开始计算，以 `speed: 1` 为准；其他倍率将所有耗时按 `1 / speed` 缩放。

| 相对时间 | 动作 | 视觉重点 |
| --- | --- | --- |
| 0–0.56 秒 | 撕下的条带飞走 | 条带继续上翻并淡出，伴随撕裂声 |
| 0–1.3 秒 | 开口喷出彩虹 | 8 条高饱和彩虹条带从开口呈扇形描出再收尾，同时喷出彩纸和火花；本包有传说卡时开口闪金光并喷出金色星星 |
| 0.21–1.9 秒 | 卡片飞出并错峰落位 | 卡片从开口向上飞出，水平散开成一排，轻微回弹；传说卡额外延后 0.18 秒压轴 |
| 0.42–1.37 秒 | 卡包让位 | 卡包下坠淡出 |
| 每张落位时 | 稀有度反馈 | 按稀有度播放不同音高的落卡声；史诗卡出现脉动光晕，传说卡出现旋转光芒、金色星光和闪光 |
| 约 2 秒后 | 展示结果 | 结果保持，状态栏报出最高稀有度卡，等待用户重开 |

## 换皮时保留的关系

卡包、撕口、彩虹和卡片共用同一个出场点，也就是卡包顶部开口。撕包由用户控制节奏，撕开之后的演出自动完成。五卡的错峰用于产生层次，不应让用户感觉需要等待五次独立抽卡。

用户提供新卡面或品牌时，替换视觉素材、颜色与文案，保留上述节奏即可。默认 foil 配色、角色图案、彩虹配色和细小倾角都是可调的实现选择，不必固定为唯一风格。
